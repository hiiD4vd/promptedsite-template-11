# promptedsite-template-11

> **The Motion Prompt Atelier** — A cinematic WebGL, Three.js & React 19 interactive experience curated for modern AI code editors (Cursor, Lovable, Bolt.new, v0).

---

## ✦ Overview

PromptedSite Template 11 is an ultra-premium interactive template featuring:
- **Headless HydraX WebGL Engine**: Ultra-smooth 60fps 3D rendering pipeline with physics and camera tracks.
- **Kinetic Typography & Parallax**: Real-time shader dissolve effects and scroll-synchronized motion.
- **3D Interactive Product Carousel**: Custom cylinder UV-mapped bottle shaders with physics wobble and smooth touch/drag controls.
- **Dark Obsidian Aesthetics**: Ultra-dark palette (`#08080C`) paired with radiant violet/purple neon glows (`#7C5CFF`, `#A78BFA`).
- **Spatial Audio Experience**: Multi-layered ambient soundscapes with browser-safe audio unlocking.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **3D / WebGL**: Three.js / Custom GLSL Shaders / HydraX Engine
- **Styling**: Modern Vanilla CSS Design Tokens
- **Icons**: Custom Kinetic Spark Monogram Vector (`✦`)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
